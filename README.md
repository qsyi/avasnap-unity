# AvaSnap連携 (jp.qsyi.avasnap)

デスクトップアプリ[AvaSnap](https://github.com/qsyi/AvaSnap)との連携用Unityエディタ拡張です。設定画面やメニューはありません。パッケージを入れるだけでバックグラウンドで自動的に動作します。

## カメラ構図補助線(FOVガイド)

AvaSnapの位置合わせモードで「取得」ボタンが押されるたびに、`Camera.main`の実際のFOV・ピッチ・ロールを一度だけファイルに書き出します(エディタモード/プレイモード問わず)。AvaSnap側はこれを読み取り、遠近ガイド線として表示します。Unityでカメラを動かしても自動では追従せず、押されるたびのスナップショット取得です。

リクエストが来るまでカメラの処理は行いません(`FileSystemWatcher`が主、環境によっては発火しないことがあるため0.5秒おきにリクエストファイルの更新日時だけを軽く確認するフォールバック付き)。出力先は `%AppData%\AvaSnap\unity_camera_guide.json` です。
